# Formula Hub

Build a clean, modern educational platform for high school students following the Nepal NEB and India CBSE curriculums, focused on physics formulas but structured so additional subjects like chemistry and biology can be added later without rebuilding the site. The homepage shows subject categories as clickable cards, starting with Mechanics, Heat and Thermodynamics, Wave and Optics, Electricity and Magnetism, and Modern Physics. Each category opens a clean list page showing every formula with its name, the equation written clearly, a short explanation of its use, and its variables defined. Include a search bar to find formulas by name or variable. Design should be minimal and mobile responsive, light theme, one accent color, good typography for fast scanning. Structure content so free formulas are visible to everyone, with a placeholder for premium, locked content to add later. Also include a separate admin login page where I can add, edit, and delete formulas and subjects through a simple form, without editing code directly. Keep the codebase simple and modular since I'll expand this over time.
